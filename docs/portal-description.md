# Crash Site Extended

Turn the original crash site into useful, circuit-connected storage without changing its vanilla appearance.

![Crash-site spaceship connected to the circuit network](https://raw.githubusercontent.com/kardagan/factorio-crash-site-extended/master/docs/crash-site-circuit-network.png)

Crash Site Extended upgrades the spaceship and inventory-bearing wreckage already created at the beginning of a Freeplay game. It does not add a craftable item, recipe, technology, custom interface, or replacement entity.

## Features

- Main crashed spaceship: 100 inventory slots
- Two large wrecks: 50 inventory slots each
- Three medium wrecks: 25 inventory slots each
- Red and green circuit-wire connections on all six containers
- Standard circuit-network inventory reading
- Original graphics, placement, mining behavior, and contents are preserved

## Existing saves

The mod modifies the original vanilla prototypes directly. When it is enabled on an existing save, any surviving crash-site spaceship and supported wrecks are upgraded in place. Their position and stored items are preserved.

Entities that were previously mined or destroyed are not recreated.

## Removing the mod

Before disabling the mod, empty every inventory slot beyond the original vanilla capacities. Removing the mod restores the smaller vanilla inventories, so items stored in the additional slots may be lost.

## Requirements

- Factorio 2.1
